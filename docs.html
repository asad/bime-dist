A short animated walkthrough of the main user flow: draw and clean structures, edit properties, quick-load examples, search the built-in library, label reactions, export outputs, and draw reactions with >> on the same canvas.

An optional JSX storyboard source is available at tools/demo/DemoWalkthrough.jsx — drop it into a React app to render the same storyboard as an interactive component.

Quick Start

Embed BIME in any web page. Pick one of two options.

Option A — Single bundle (recommended)

One signed script tag, a container, and an init call:

<script src="https://asad.github.io/bime-dist/dist/bime.min.js"
        integrity="sha384-PASTE-HASH-FROM-dist/SRI.txt"
        crossorigin="anonymous"></script>
<div id="editor" style="width:100%;height:500px"></div>
<script>
var editor = new MolEditor('editor', '100%', '500px', { options: 'hydrogens' });
editor.readGenericMolecularInput('c1ccccc1');
</script>

Copy the integrity hash from dist/SRI.txt. The minified bundle is ~900 KiB and ships with SHA-384 Subresource Integrity so the browser refuses tampered loads.

Option B — Individual modules (advanced)

For users who want module-level control, the 15 individual script files are also published. Order matters; load them in this sequence:

<!-- 1. Include scripts (from GitHub Pages CDN) -->
<script src="https://asad.github.io/bime-dist/editor/Molecule.js"></script>
<script src="https://asad.github.io/bime-dist/editor/Layout.js"></script>
<script src="https://asad.github.io/bime-dist/editor/Templates.js"></script>
<script src="https://asad.github.io/bime-dist/editor/SmilesParser.js"></script>
<script src="https://asad.github.io/bime-dist/editor/SmilesWriter.js"></script>
<script src="https://asad.github.io/bime-dist/editor/MolfileWriter.js"></script>
<script src="https://asad.github.io/bime-dist/editor/Renderer.js"></script>
<script src="https://asad.github.io/bime-dist/editor/History.js"></script>
<script src="https://asad.github.io/bime-dist/editor/Tools.js"></script>
<script src="https://asad.github.io/bime-dist/editor/CIPStereo.js"></script>
<script src="https://asad.github.io/bime-dist/editor/SmartsParser.js"></script>
<script src="https://asad.github.io/bime-dist/editor/SmartsMatch.js"></script>
<script src="https://asad.github.io/bime-dist/editor/SmartsWriter.js"></script>
<script src="https://asad.github.io/bime-dist/editor/ImageExport.js"></script>
<script src="https://asad.github.io/bime-dist/editor/MolEditor.js"></script>

<!-- 2. Add a container -->
<div id="editor" style="width:100%;height:500px"></div>

<!-- 3. Create the editor -->
<script>
var editor = new MolEditor('editor', '100%', '500px', {
    options: 'hydrogens'
});
editor.readGenericMolecularInput('c1ccccc1');  // Load benzene
</script>

Either way: no build step, no npm, no bundler. Works from a local file or any web server.

SMILES & Validation

BIME includes a strict SMILES parser that validates input and reports detailed errors:

// Valid molecule
editor.validateSmiles('c1ccccc1');
// { valid: true, atoms: 6, bonds: 6, smiles: 'c1ccccc1', error: null, warnings: [] }

// Unclosed ring
editor.validateSmiles('C1CCC');
// { valid: false, error: 'Unclosed ring 1 opened at position 1' }

// Valence violation (warning, not error)
editor.validateSmiles('C(C)(C)(C)(C)C');
// { valid: true, atoms: 6, warnings: ['Valence violation: atom C has 5 bonds but max standard valence is 4'] }

// Unknown atom
editor.validateSmiles('XYZ');
// { valid: false, error: 'Unknown atom symbol "X" at position 0' }

// Reaction SMILES
editor.validateSmiles('CCO>>CC=O');
// { valid: true, atoms: 6, bonds: 4 }

// Atom-mapped reaction
editor.validateSmiles('[CH3:1][OH:2]>>[CH2:1]=[O:2]');
// { valid: true, atoms: 4 }

SMARTS Substructure Search

Search for substructure patterns using SMARTS notation. BIME includes a constraint-based matching engine.

// Match a SMARTS pattern against the current molecule
var count = editor.matchSmarts('[#6]~[#7]');  // carbon bonded to nitrogen
// Returns number of matches found; matching atoms are highlighted in teal

// Programmatic matching
var mol = new Molecule();
SmilesParser.parse('Cn1c(=O)c2c(ncn2C)n(C)c1=O', mol);  // caffeine

var query = new Molecule();
SmartsParser.parse('[#7]', query);  // any nitrogen

var mappings = SmartsMatch.match(mol, query);  // all nitrogen positions
console.log(mappings.length);  // 4 (caffeine has 4 nitrogens)

// Highlight matches
SmartsMatch.highlightMatches(mol, query);  // sets atom.highlighted = true

Image Export (SVG / PNG)

Export molecules as publication-quality images.

// SVG export (self-contained, no external CSS)
var svg = ImageExport.toSVG(editor.molecule, {
    width: 400, height: 300,
    padding: 40,
    background: '#ffffff',
    bondWidth: 2.5,       // thicker for print
    fontSize: 16,         // larger for print
    showHydrogens: true,
    watermark: true       // "Generated by BIME" in corner
});

// Download as SVG file
ImageExport.downloadSVG(svg, 'caffeine.svg');

// PNG export at 4x resolution (publication quality)
ImageExport.toPNG(editor.molecule, { scale: 4 }).then(function(blob) {
    ImageExport.downloadPNG(blob, 'caffeine.png');
});

// Copy to clipboard (for pasting into documents)
ImageExport.copyToClipboard(editor.molecule);

// Print-ready SVG (thicker lines, larger fonts, CMYK-safe colours)
var printSvg = ImageExport.toPrintSVG(editor.molecule);

// Batch export (1181 molecules → 1181 SVGs)
var svgs = ImageExport.batchSVG(COMMON_MOLECULES, { width: 300, height: 200 });

Molecule Naming

BIME identifies molecules by matching against a built-in offline database of 1181 canonical compounds (drugs, amino acids, nucleotides, vitamins, common reagents). No external network calls — your structure never leaves the page.

// Auto-name from 1181 built-in molecules
editor.readGenericMolecularInput('CC(=O)Oc1ccccc1C(=O)O');
console.log(editor.getMolName());  // "Aspirin" (matched from local database)

// Set name manually
editor.setMolName('My Custom Molecule');

// Local-only auto-name (Promise-based; resolves from the built-in database
// or returns null if no match)
editor.autoName().then(function(name) {
    console.log(name);
});

The molecule name can be displayed on the drawing canvas. In the Workbench, use Editor Output → Properties to edit molecule or reaction name, export comment, canvas-name visibility, and reaction-arrow label fields. The name and comment are included in MOL/RXN/SDF headers and SVG image metadata.

Note: earlier alpha builds queried an external name resolver for IUPAC names. That channel was removed in v1.0.1; getIUPACName() and related methods are retained as no-op stubs for backwards compatibility but no longer make network calls.

The Workbench compound lookup is a separate optional public compound-data integration. It can load structures from name, CAS, IUPAC-style names, formula, CID, InChI, or InChIKey, then routes the result through the same molecular input parser used by typed SMILES/MOL/RXN imports.

Reactions & Atom Mapping

Draw reactions with the arrow tool and map atoms between reactants and products.

// Load a reaction SMILES
editor.readGenericMolecularInput('CCO>>CC=O');

// Load with atom-atom mapping
editor.readGenericMolecularInput('[CH3:1][OH:2]>>[CH2:1]=[O:2]');

// Retrosynthetic arrow
editor.readGenericMolecularInput('CC=O=>CCO');

// Multi-component reaction (with + signs between fragments)
editor.readGenericMolecularInput('CC(=O)O.OCC>>CC(=O)OCC.O');

Use the Arrow tool to draw reaction arrows, and the Map tool to click atom pairs for mapping.

Stereochemistry (CIP R/S, E/Z)

BIME assigns CIP stereochemistry labels using the Cahn-Ingold-Prelog priority algorithm.

// Load a chiral molecule
editor.readGenericMolecularInput('[C@@H](F)(Cl)Br');

// CIP labels are computed automatically
// Enable display: editor.options('showcip');

// Programmatic access
CIPStereo.assign(editor.molecule);
editor.molecule.atoms.forEach(function(atom) {
    if (atom.cipLabel) console.log(atom.symbol + ': ' + atom.cipLabel);
    // "C: R"
});

// E/Z for double bonds
editor.molecule.bonds.forEach(function(bond) {
    if (bond.cipLabel) console.log('Bond: ' + bond.cipLabel);
    // "Bond: E" or "Bond: Z"
});

2D Layout

BIME generates publication-quality 2D coordinates from any SMILES through a 16-step native JavaScript pipeline. The editor/sdg/* package (12 modules) implements BIME's structure-diagram generator. Apache-2.0 throughout.

Layout quality on the standard regression suite:

MetricResult
SSSR rings clean (max/min ≤ 1.05)>93 %
Per-mol mean clean rate>96 %
Atom overlaps0
Determinismbyte-identical coords across runs (locked)
Advanced: full 16-step pipeline phases 
// Steps 1-3:  SSSR ring perception (GF(2) cycle-basis selection)
// Step 4a:    Largest ring system at origin
// Step 4b-c:  Chain & substituent placement (zigzag, fan-arc)
// Step 5:     Bond-length normalisation
// Step 6:     Spatial-grid collision resolution
// Steps 7-9:  Orientation, atom-bar, sugar-axial conventions
// Step 10:    Crossing / ring-overlap detection
// Step 11:    Force-directed crossing reduction (when needed)
// Step 12:    ML residual refinement (opt-in, off by default)
// Step 13:    Collapsed-ring + collapsed-chain rescue
// Step 14:    SDG corrective pass (OverlapResolver, distributePartners)
// Step 15:    Fused-ring polygon snap (v1.8.15-16)
//             - snapRingAtCentroid15  → MacroCycleLayout for size 8+
//             - snapFusedRingByReflection15
//             - snapSpiroRingFromAtom15
//             - relaxChainBonds15 (chain bonds → BL, rings frozen)
//             - separateOverlappingRingSystems15 (rigid translation)
//             - resolveChainOverlaps15 (chain-only collisions)
// Step 16:    SDG refinement (v1.8.17)
//   16a       CorrectGeometricConfiguration (E/Z reflection, full CIP)
//   16b       NonplanarBonds.assign (sp³ wedge/dash → bond.depictStereo)
//   16c       LayoutRefiner.alignToLongestAxis (PCA rotation)
//   16d       LayoutRefiner.rotateRings (try-180°-pick-lower-Congestion)
//   16e       HydrogenPlacer (explicit H atoms → opposite heavy centroid)
//   16f       linearizeMacroChain19 (multi-strategy with safety revert)

All pipeline steps are independently controllable through Layout.options:

Layout.options = {
    enforceConventions:   true,   // sugar / aromatic / chain conventions
    useMLDepict:          false,  // opt-in ML residual refiner
    mlDepictWeight:       0.15,
    useSDG:               true,   // v1.8.12 corrective pass
    useSDGRefine:         true,   // v1.8.17 step 16
    correctEZ:            true,   // v1.8.19 — full CIP priorities
    assignWedgeDash:      true,   // v1.8.19 — depictStereo, safe round-trip
    alignToLongestAxis:   true,   // PCA rotation
    rotateRings:          true,   // try-180°-per-ring
    placeExplicitH:       true,   // explicit-H placement
    linearizeMacroChain:  true    // v1.8.19 — multi-strategy with safety revert
};

Testing & Auditing

BIME ships with a comprehensive, multi-tier regression battery that runs in plain Node with zero dependencies in a few seconds. Every full release gate runs the same suites in lockstep across source, integration, bundle, and minified-bundle checks:

  • The full source suite across the tests/ directory — parser, writer, SMARTS, substructure, MCS, aromaticity, H counting, round-trip, history, layout, CIP R/S, atom-atom mapping, release integrity, etc.
  • An integration suite for the layout pipeline.
  • A bundle suite that re-runs the source tests against dist/bime.js.
  • A minified-bundle suite that re-runs them against dist/bime.min.js — proving the minifier preserves every behaviour.
# Full unit suite
node tools/run-tests.js

# Integration verification
node tools/verify-v1817.js

# Bundle + minified-bundle regression (run by tools/build.js)
node tools/build.js

# Database integrity audit
node tools/audit-aromatic.js

The tests are organised one file per concern under tests/:

The aromaticity audit tool catches mass-canonicalisation regressions (aromatic ribose, peroxides, β-lactams, cyclohexane, etc.) and reports 0 issues across all 1181 molecules in the current database.

Architecture

BIME is organised as a set of single-responsibility modules in two layers:

editor/
  Molecule.js        Molecular graph (atoms, bonds, rings, components)
  Layout.js          2D coordinate generation (16-step pipeline)
  Templates.js       Public scaffold templates
  SmilesParser.js    Strict SMILES parser with validation
  SmilesWriter.js    Canonical SMILES writer
  MolfileWriter.js   MOL V2000 / V3000 export
  Renderer.js        SVG renderer (atoms, bonds, arrows, maps)
  History.js         Undo / redo stack
  Tools.js           Interactive drawing tools
  CIPStereo.js       CIP R/S + E/Z stereochemistry
  SmartsParser.js    SMARTS pattern parser
  SmartsMatch.js     SMARTS matcher
  SmartsWriter.js    SMARTS pattern writer
  ImageExport.js     Publication SVG, hi-res PNG, clipboard
  MolEditor.js       Main editor class (UI, toolbar, events, API)
  SMSDGraph.js       Chemical graph backing for substructure / MCS
  SMSDRings.js       Ring perception
  SMSDMCS.js         Maximum common substructure
  SMSDLayout.js      Force-directed layout, crossing reduction
  SDGLayout.js       Corrective layout pass
  MLDepict.js        Optional ML coordinate refiner
  RDT.js             Reaction atom-atom mapping
  ToolbarPrefs.js    Toolbar customisation persistence
  ml-depict-weights.js  Embedded ML weights

editor/sdg/         Native JavaScript structure-diagram generator
  StructureDiagramGenerator.js   Top-level orchestrator
  RingPlacer.js                  Regular / fused / spiro / bridged / macrocycle ring placement
  MacroCycleLayout.js            Egg-shape ovalisation (size 8+, every bond ≤1% off BL)
  AtomPlacer.js                  distributePartners, placeLinearChain, populatePolygonCorners
  HydrogenPlacer.js              Explicit-H placement opposite heavy-neighbour centroid
  Congestion.js                  Pairwise inverse-square score for layout comparison
  OverlapResolver.js             Summed-force iterative overlap resolution
  LayoutRefiner.js               alignToLongestAxis (PCA), rotateRings (try 180°), refine
  NonplanarBonds.js              Tetrahedral wedge/dash assignment (writes depictStereo)
  CorrectGeometricConfiguration.js  E/Z reflection using full CIP priorities
  TemplateHandler.js             Scaffold lookup with subgraph isomorphism atom mapping (+ greedy fall-back)
  IdentityTemplateLibrary.js     User-defined template store

The editor/sdg/* package is BIME's native JavaScript SDG implementation. Every module is a working implementation; no stubs.
