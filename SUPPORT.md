# Getting help with BIME

BIME is a browser-based 2D molecule editor distributed under
Apache 2.0.

---

## Quick links

- **Workbench:** <https://asad.github.io/bime-dist/workbench.html>
- **Docs:** <https://asad.github.io/bime-dist/docs.html>
- **Examples:** <https://asad.github.io/bime-dist/examples.html>
- **Issue tracker:** <https://github.com/asad/bime-dist/issues>

---

## Reporting issues

- **Bugs and feature requests:**
  <https://github.com/asad/bime-dist/issues>

  Please include the BIME version, browser, exact steps to reproduce,
  and a minimal SMILES that triggers the problem.

- **Security vulnerabilities:** please do **not** open a public issue.
  Email **info@bioinceptionlabs.com** with details. Acknowledgement
  within 5 working days; fix coordinated before public disclosure.
